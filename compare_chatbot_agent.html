So sánh Chatbot và Agent

Trang này giải thích sự khác biệt giữa một chatbot LLM thông thường và một agent tư vấn tuyển sinh sử dụng Gemini.

Khác biệt chính

Tiêu chí Chatbot Agent tuyển sinh
Luồng xử lý Trả lời trực tiếp theo prompt. Thực hiện suy nghĩ, gọi tool, quan sát rồi mới trả lời.
Khả năng tùy biến Phù hợp trả lời tổng quát. Phù hợp tư vấn chuyên sâu, so sánh và tra cứu thông tin.
Ứng dụng Hỏi đáp nhanh, hội thoại tự nhiên. Tuyển sinh đại học, hỗ trợ quyết định, phân tích yêu cầu.
Độ tin cậy Phụ thuộc mô hình và prompt. Tăng cường nhờ công cụ và cấu trúc hành động.

Agent sử dụng Gemini

Trong dự án này, agent:

  • Khởi tạo thư viện google.generativeai.
  • Gọi API Gemini để sinh câu trả lời.
  • Sử dụng luật định dạng ReAct để gọi các công cụ tuyển sinh.

Ưu điểm khi so sánh

  • Agent có cấu trúc hơn và dễ kiểm soát hơn so với chatbot thuần túy.
  • Agent có thể tự động chọn đúng công cụ xử lý, giảm tải việc cầu cứu thông tin.
  • Agent phù hợp với các tiến trình tư vấn tuyển sinh phức tạp và nhiều bước.
