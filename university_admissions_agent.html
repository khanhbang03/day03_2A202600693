Agent Tư Vấn Tuyển Sinh Đại Học

Trang này mô tả agent chuyên dụng tư vấn tuyển sinh đại học, hoạt động với Gemini để đưa ra gợi ý ngành học, trường học và yêu cầu tuyển sinh.

Giới thiệu

Agent sử dụng mô hình Gemini để hiểu câu hỏi thí sinh và thực hiện các công cụ hỗ trợ như:

  • Tìm chương trình phù hợp theo ngành, thành phố và điểm thi.
  • Giải thích yêu cầu tuyển sinh cho trường hoặc ngành cụ thể.
  • So sánh hai trường hoặc hai chương trình để chọn lựa phù hợp.

Cách dùng

Chạy script Python sau để tương tác với agent:

python src/run_admissions_agent.py

Yêu cầu:

  • Sao chép .env.example thành .env.
  • Thiết lập GEMINI_API_KEY với API key của bạn.

Ví dụ câu hỏi

Tư vấn ngành Công nghệ thông tin ở Hà Nội.
So sánh HUST và VNUHCM.
Yêu cầu tuyển sinh ngành Khoa học Máy tính ở HUST là gì?

Gợi ý thiết kế agent

Agent được xây dựng theo mô hình ReAct, kết hợp:

  • Hệ thống `GeminiProvider` để gọi Gemini.
  • Lớp `ReActAgent` để sinh suy nghĩ, hành động, quan sát và trả lời.
  • Các công cụ chuyên dụng tuyển sinh trong src/agent/admissions_agent.py.
